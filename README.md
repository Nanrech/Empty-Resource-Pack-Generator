# Empty Resource Pack Generator
This is a small python tool that generates "empty" resource packs for the latest Minecraft release/snapshot.
The resource packs generated by this tool have the following structure:

```
Empty Language Resource Pack ({version}).zip/
  assets/
    minecraft/
      lang/
        en_usk.json
        en_us.json
  pack.png
  pack.mcmeta
```

These resource packs add two language files to the game
- `en_usk.json` aka "English (Translation Keys)" is a new language (you can select this language through the language menu in-game) that replaces every string's text with its translation key. For example, instead of seeing "Diamond pickaxe" in game, you'd see "item.minecraft.diamond_pickaxe".
- `en_us.json` is identical to the en_us.json found in the client's assets. I have chosen to provide this file in case the user wants to use the original strings as a base for their own language resource pack, or simply want to make small edits to see them in game without having to deal with translation keys.
